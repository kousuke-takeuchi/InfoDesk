# 機能インベントリ

[設計書](../superpowers/specs/2026-10-06-infodesk-design.md)の節ごとに、実装済みか未実装かを棚卸しする。判定は2026-10-11時点のコードを読んで行い、根拠のファイルを備考に書く。

- **実装済み**: 設計書の記述どおりに動くコードがある。
- **未実装**: コードが無い、または設計書の一部を満たしていない(満たしていない部分を備考に書く)。
- 設計書から意図的に変えた点は「差分」と書く。

## 1. 目的

| 項目 | 状態 | 備考 |
|---|---|---|
| 当日のカテゴリー別要約が、開いた時点で生成済み | 実装済み | 収集のたびに当日の日次要約を作り直し(`jobs::collect_inner`)、日次の時刻に前日を確定する(`scheduler.rs`) |
| 記事一覧をカテゴリー、トピック、期間、ソースで絞り込める | 実装済み | `FeedView`、`ItemFilter`、サイドバーの選択 |
| 設定画面からRSSを追加し、次回の収集から反映 | 実装済み | `add_rss_source`。追加時に1回取得して検証する |
| 要約はローカルLLMだけで完結し、設定でClaudeに切替 | 実装済み | `llm/ollama.rs`、`llm/claude.rs`、`provider_from_settings` |
| ウィンドウを閉じても収集と要約が続く | 実装済み | `app.stay_resident`、`lib.rs` の `CloseRequested` |
| 対象外: 複数ユーザー、同期、モバイル | 未実装 | 意図的に対象外 |
| 対象外: `bge-m3` による意味検索 | 未実装 | 意図的に対象外(キーワード照合のみ) |
| 対象外: 収集時の記事本文の取得 | 未実装 | 意図的に対象外。本文はチャットの `fetch_page` が必要な記事に限り取得し、保存しない |
| 対象外: プッシュ通知 | 未実装 | 意図的に対象外 |
| 対象外: Windows、Linux | 未実装 | 意図的に対象外。macOSのみ |
