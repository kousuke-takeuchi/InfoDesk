# キーボードショートカット

InfoDesk はキーボードで操作できます。どこでも `?` を押すと、アプリ内に一覧が開きます。閉じるには `Esc` を押します。修飾キーは macOS では Command、それ以外のキーボードでは Ctrl です。

## 1. 全体のショートカット

| キー | 動作 |
|---|---|
| `Cmd+R` / `Ctrl+R` | 今すぐ収集し、表示も更新 |
| `1` / `2` | ダイジェスト / フィード |
| `d` / `w` / `m` | 期間: 今日 / 週 / 月 (フィードでは直近1週間 / 1ヶ月) |
| `[` / `]` | サイドバーの前 / 次の項目 (端では反対側へ回る) |
| `0` | サイドバーの「すべて」を選択 |
| `Cmd+J` / `Ctrl+J` | チャットパネルの開閉 |
| `Cmd+,` / `Ctrl+,` | 設定を開く |
| `?` | ショートカットの一覧を開く |

サイドバーの並びは、すべて、カテゴリー、トピックの順です。

## 2. フィードのショートカット

フィードの画面でだけ使えます。

| キー | 動作 |
|---|---|
| `j` / `k` | 次の記事 / 前の記事 |
| `Enter` | 選んだ記事をリーダーで開く |
| `u` | 既読と未読の切り替え |
| `s` | スターの切り替え |
| `/` | 検索欄にフォーカス |
| `Shift+A` | 現在の絞り込みに合う記事をすべて既読にする |

ダイジェストの画面では、全体のショートカット (期間の `d`、`w`、`m` を含む) だけが使えます。

## 3. ショートカットが無効になる場面

- **入力中**: フォーカスがテキスト欄、テキストエリア、セレクト、編集可能な領域 (検索欄、チャットの入力、設定の入力欄) にあるときは、何も動きません。
- **IME の変換中**: 文字を変換している間 (たとえば日本語入力) のキーは無視します。
- **ダイアログが開いているとき**: モーダルのダイアログ (ショートカットの一覧自体を含む) が開いている間は、すべてのショートカットが止まります。
- **設定の画面**: 使えるのは `Cmd+R`、`Cmd+,`、`Cmd+J`、`?` だけです。ほかのキーは、設定を誤って変えないよう無視します。
- **ボタン、リンク、summary の上**: `Enter` は、選んだ記事を開く代わりに、そのコントロールを押す通常の動作になります。
- **ほかの修飾キー付き**: Ctrl、Command、Alt を押しているときは、単独のキーは働きません (`Shift` は `?` と `Shift+A` だけで使います)。

## 4. 表示を新しく保つ

ウィンドウがフォーカスを取り戻したとき、再び表示されたとき、ローカルの日付が変わったとき (1分ごとに確認) に、データを読み込み直します。Mac がスリープしたあとや、アプリがメニューバーに常駐したままでも、ダイジェストとフィードが前日の表示のまま残りません。
