# ダイジェスト

ダイジェストは、ある期間の日本語の要約です。ツールバーの**ダイジェスト**の切替で開きます。

## 1. 期間

ツールバーの切替で**今日**、**週**、**月**を選びます。画面にはいつも現在の期間が出て、見出しにその日付が出ます。

| 期間 | 開始 | 終了 (含まない) |
|---|---|---|
| 日 | ローカルの0時 | 次のローカルの0時 |
| 週 | 月曜のローカルの0時 | 次の月曜 |
| 月 | 1日のローカルの0時 | 翌月の1日 |

境界はローカルのタイムゾーンで決まります。期間は半開区間で、開始を含み、終了を含みません。

## 2. ダイジェストの作り方

ダイジェストは階層で作るので、長い期間は短い期間の要約から作ります。

- **日**: カテゴリーごとに、その日の記事のタイトルと記事要約をモデルに読ませます。
- **週**: カテゴリーごとに、その週の日次要約を読ませます。
- **月**: カテゴリーごとに、その月に重なる週の週次要約を読ませます。月初を含む週から月末を含む週までです。2つの月にまたがる週は、両方の月に入ります。
- 期間に記事の無いカテゴリーは、ダイジェストを作りません。
- 各ダイジェストは根拠にした記事の一覧を持ち、書いたプロバイダー (例: `ollama:gemma4:26b`) と記事数を表示します。

記事要約と期間要約のプロバイダーは別の設定 (`llm.items_provider`、`llm.digest_provider`) です。件数の多い記事要約は Ollama、ダイジェストは Claude、という使い分けができます。

今日の要約は収集では作られません。「生成」(または「再生成」)を押して作ります。日は、終わった翌朝の日次の時刻に自動で確定します。ダイジェストを作る時刻は[ソースとトピック](03-sources-and-topics.ja.md#5-収集のスケジュール)にあります。

## 3. カテゴリー別とトピック別

サイドバーの選択で表示が決まります。

- **すべて**または**カテゴリー**: カテゴリーごとの節 (カテゴリーを選んだときはその1つ)。
- **トピック**: そのトピックの節が1つ。一致した記事のタイトルと要約から、その場で作ります。そのトピックと期間で**生成**を押すと作られ、結果は保存されて再利用されます。

各節には、その要約についてチャットで質問するボタンがあります。

## 4. 期間の概観

画面の上部に、データベースの集計だけで描く概観が出ます。LLM は使いません。記事は取得した日時で数え、期間の境界は上と同じです。

- **カテゴリー別の件数**: 横棒グラフ。週と月では、各カテゴリーの右に日ごとの件数の小さな折れ線が付きます。
- **話題の強さ**: トピックごとの記事数と、前の同じ長さの期間 (前日、前週、前月) からの増減。増えたものは上向き、減ったものは下向きの矢印、変わらないものは横線です。トピックを1つ選んでいるときは、そのトピックだけです。

グラフは色だけに頼らず、棒の横に数値も出します。

## 5. 節の読み方

作成が終わったダイジェストでは次を表示します。

- **見出し**: ダイジェストの1行目を大きく表示します。モデルには40字以内の1行を求めます。この機能の前に作ったダイジェストには見出しが無く、そのまま文章で表示します。
- **番号付きの要点**: 本文を番号付きの一覧で表示します。
- **画像カード**: 根拠にした記事のうち、https の画像を持つ最初の3件を、カード (画像、タイトル、ソース名) で並べます。カードを押すと[閲覧ウィンドウ](05-feed-and-reader.ja.md#2-閲覧ウィンドウ)で記事を開きます。画像が読み込めなかったカードは、文字のリンクに戻ります。
- **根拠記事**: 残りの記事は文字のリンクで並び、残りの件数も出ます。

## 6. 再生成、保留、失敗

見出しの**再生成**を押すと、表示中の節を作り直します。状態は節ごとで、1つの失敗が他に影響することはありません。

| 状態 | 意味 | できること |
|---|---|---|
| 生成中 | モデルが書いています | 待つ |
| 保留中 | 生成に失敗し、自動で再試行します。最後のエラーを表示 | **今すぐ再試行** |
| 失敗 | 生成に3回失敗しました。回数と最後のエラーを表示 | LLM の設定を確認して**再試行** |
| 未生成 | 記事はあるが要約が無い | **生成** |
| 記事なし | この期間に収集した記事が無い | なし |

失敗した試行は、3回目の失敗までは保留中に戻り、3回目で失敗になります。スケジューラーは保留中の要約を自動で再試行します。再試行は他のジョブの有無にかかわらず、15分に1回までです。失敗になった要約は、**再試行** (または設定のスケジュールタブの再試行ボタン) を押したときだけ再試行します。成功すると回復します。
