# ロードマップ

InfoDesk は、バージョン 0.1.0 のアルファ版で、個人のプロジェクトです。このページには、作ったもの、分かっている制限、いくつかのアイデアを記します。アイデアは約束ではありません。予定の日程もありません。

設計の spec と実装計画は `docs/superpowers/` にあります。

## 完了したもの

作業は計画ごとに進めました。下の1行が1つの計画です。

- **Phase 0、画面設計**: アプリのコードより先に、すべての画面を `design.pen` で設計し、確認しました。
- **Plan 1、core と CLI**: `infodesk-core` ライブラリ (収集、全文検索つきの SQLite ストア、LLM プロバイダー、記事要約と階層式の期間要約) と `infodesk` CLI。[CLI](08-cli.ja.md) を参照。
- **Plan 2a、アプリのバックエンド**: Tauri のアプリ状態、コマンド、収集と要約のジョブ、取りこぼしを補うスケジューラー、メニューバー、ログイン時の起動。[設定](07-settings.ja.md)を参照。
- **Plan 2b、アプリの UI**: ダイジェスト、フィード、設定の React 画面。ライトとダークのテーマ。[ダイジェスト](04-digests.ja.md)と[フィードと閲覧](05-feed-and-reader.ja.md)を参照。
- **Plan 3、チャット**: 右側のチャットパネル、Node のエージェント (サイドカー)、スレッド、文脈のチップ、Ollama と Claude のプロバイダー、ツール。[AI チャット](06-ai-chat.ja.md)を参照。
- **Plan 4、サムネイルと途中経過**: フィードに出す記事の画像 (フィードの画像、なければ `og:image`) と、チャットの途中経過の表示 (計画、思考、ツールの手順、経過時間)。
- **Plan 5、視覚的なダイジェストと閲覧**: 期間の概観 (棒、日ごとの推移、トピックの強さ)、見出しと番号つきの箇条書きと画像カード、ツールバーつきのアプリ内の閲覧ウィンドウ。

## 分かっている制限

- **macOS のみ。** 動作確認は Apple Silicon です。Windows と Linux は対象外です。
- **LLM のプロバイダーは2つ。** Ollama と Claude CLI です。API キーで直接呼ぶプロバイダーはありません。
- **要約はフィードの文章が元。** 収集は、フィードや API が返すタイトルと概要を保存します。記事の本文は取得しません。本文を取得するのは、チャットのエージェントが求めたときだけです。
- **キーワード照合のみ。** 検索とトピックはキーワードで照合します。意味検索はありません。
- **API キーは平文。** ollama.com のキーは、DB に暗号化せずに保存されます。[プライバシーとセキュリティ](09-privacy-and-security.ja.md)を参照。
- **チャットは読み取り専用で上限あり。** エージェントはデータを変更できません。1回の回答は、Ollama が20ステップ、Claude が20ターンまでで、Ollama のチャットの文脈長は 16384 トークンです。
- **チャットのスレッド名は画面から変えられない。** タイトルは最初の質問から付きます。(ストアは名前の変更に対応していますが、パネルには操作がありません。)
- **Claude の自動フォールバックなし。** Claude が失敗しても、自動では Ollama に切り替わりません。
- **利用者は1人。** 同期、複数ユーザー、モバイルはありません。
- **通知なし。** メニューバーに状態と未読の件数は出ますが、プッシュ通知は送りません。
- **スクリーンショットはサンプルデータ。** このドキュメントの画像は、モックしたバックエンドのサンプルデータです。

## アイデア

どれもアイデアにすぎません。計画も日程もありません。

- キーワード照合で足りないとわかった場合の、`bge-m3` などの埋め込みモデルによる意味検索。spec が後の選択肢として挙げています。
- ollama.com の API キーを、DB ではなく macOS のキーチェーンに置く。
- Ollama と Claude CLI 以外のチャットのプロバイダー。
- Windows や Linux 向けのビルド。spec は初版を macOS に限っていました。
- 要約ができたときの通知。spec は初版に含めていませんでした。
