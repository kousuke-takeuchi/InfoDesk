## InfoDesk とは

InfoDesk は、技術系と医療介護系のニュースを集め、**日次、週次、月次の日本語ダイジェスト**を作る macOS のデスクトップアプリです。Mac の中だけで動きます。記事はローカルの SQLite ファイルに保存され、要約はローカル LLM (Ollama) でも作れるので、データを外に出さずに使えます。

アルファ段階の個人プロジェクトです (バージョン 0.1.0)。対応する OS は macOS のみで、動作を確認しているのは Apple Silicon だけです。

## 想定する利用者

- 英語と日本語の複数のソースを追っていて、1日、1週間、1か月ごとに短い日本語の要約がほしい人
- 医療や介護の仕事をしていて、技術ニュースも追いたい人
- ニュースサービスではなく、ローカル LLM や手元の `claude` CLI を使いたい人

## 設計の方針

- **ローカル優先**: 記事、要約、設定、チャットのスレッドは `~/Library/Application Support/` の下の1つの SQLite ファイルに入ります。InfoDesk のサーバーもアカウントもありません。
- **ローカル LLM を使える**: 既定のプロバイダーは Ollama です。記事要約、期間要約、チャットのそれぞれを `claude` CLI に切り替えられます。
- **日本語で出力**: 元のソースが何語でも、要約とダイジェストは日本語で書きます。
- **中身を確かめやすい**: 画面は macOS の外観 (ライトとダーク) に従い、各ダイジェストは根拠にした記事へのリンクを持ちます。
